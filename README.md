# 💍 Landing Page — Proyecto en Colaboración (Ariadna & Dante)

Sitio web interactivo y moderno desarrollado en conjunto y desplegado en la nube mediante **Firebase Hosting**, diseñado con un enfoque visual elegante y optimizado para ofrecer una experiencia de usuario impecable.

🌐 **Enlace del proyecto:** [https://landing2026.web.app/](https://landing2026.web.app/)

---

## 🎯 El Problema / Propósito que Resuelve
En la era digital, la necesidad de centralizar información importante (ya sea para un evento especial, una invitación interactiva, una landing de presentación o un proyecto colaborativo) requiere una plataforma rápida, accesible desde cualquier dispositivo y con un diseño visualmente atractivo. Este proyecto resuelve esa necesidad ofreciendo una interfaz ligera, responsiva y de despliegue inmediato en la web.

---

## 👥 Autores y Colaboración
* **Ariadna Vera:** Diseño de interfaz, estructura frontend, lógica de componentes y gestión general.
* **Dante:** Desarrollo, optimización de contenidos, integración técnica y pruebas de despliegue en la nube.

---

## 🛠️ Tecnologías Usadas
* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Estilos personalizados, diseño adaptable (Responsive Design) y estética visual cuidada.
* **JavaScript (ES6):** Interactividad en el cliente y dinamismo en la interfaz de usuario.
* **Firebase Hosting:** Plataforma de alojamiento en la nube utilizada para el despliegue continuo y seguro del sitio web.
* **Git & GitHub:** Control de versiones del proyecto.

---

## 🚀 Funcionalidades Principales
* **Diseño Responsivo:** Adaptación fluida para visualizarse perfectamente tanto en computadoras de escritorio como en teléfonos móviles y tabletas.
* **Interactividad Dinámica:** Elementos visuales y componentes interactivos impulsados por JavaScript para mejorar la experiencia del usuario (UX).
* **Despliegue en la Nube:** Publicación en tiempo real optimizada a través de Firebase, garantizando tiempos de carga rápidos y alta disponibilidad.
